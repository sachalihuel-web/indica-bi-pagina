# IndicaBI / Proyecto Web Comercial

Landing page responsive desarrollada en HTML, CSS y JavaScript vanilla para presentar servicios digitales orientados a pequeños negocios y pymes.

## Objetivo del proyecto

Este proyecto forma parte del desarrollo comercial de una futura oferta de servicios enfocada en:

- páginas web profesionales;
- landing pages para negocios;
- dashboards;
- análisis de datos;
- automatización de reportes;
- inteligencia de negocios para pymes.

## Servicios relacionados

Este tipo de proyecto puede adaptarse para:

- negocios locales;
- emprendedores;
- minimarkets;
- tiendas;
- profesionales independientes;
- pequeñas empresas;
- páginas de presentación comercial;
- páginas de contacto;
- sitios informativos simples.

## Tecnologías utilizadas

- HTML5
- CSS3
- JavaScript vanilla
- Diseño responsive
- GitHub Pages

## Estado del proyecto

Proyecto en desarrollo y revisión interna.

No representa una plataforma SaaS terminada.  
Es una base web profesional para validar servicios digitales y presentación comercial.
